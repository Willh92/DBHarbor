## [v1.0.4] - 2026-11-14

### Deep Security & Supply-Chain Hardening (CodeQL Zero-Alert), 14-Driver Concurrency/Dialect Fixes, Dark Mode, Safari & Mobile UX Polish
- **Supply-Chain Security, Local CodeQL Zero-Alert Remediation & Deployment Hardening**:
  - **GitHub Actions & Build Scripts**: Pinned all third-party GitHub Actions in `release.yml` and `preview.yml` to immutable 40-character commit SHAs, added SHA-256 archive verification and log-injection sanitization in `scripts/setup-toolchain.mjs`, and eliminated TOCTOU file-system races in `scripts/build.mjs`.
  - **Container & Service Installers**: Hardened `Dockerfile` with `root:root` (`0755`) read-only binary/application directory ownership while restricting `dbharbor:dbharbor` (`0700`) write access strictly to `/app/data`; tightened ACLs and unit/plist/init quoting in `scripts/install-service.ps1` and `scripts/install-service.sh`; documented `DBHARBOR_TRUSTED_PROXIES` across reverse-proxy templates (`deploy/*`).
- **Backend Authentication, RBAC, Vault & Desktop Local-Origin Hardening**:
  - **Vault, Login Rate-Limiting & Atomic 2FA**: Guarded `.master.key` creation (`O_CREATE|O_EXCL` only on `os.ErrNotExist`) so corrupted/unreadable key files are never silently overwritten; scoped `LoginProtector.RecordSuccess` IP failure subtraction to `(ip, username)` pairs to prevent unrelated account sign-ins from clearing brute-force IP tallies; enforced atomic single-use CAS updates in `Store.Verify2FA` against concurrent TOTP or recovery-code replay.
  - **TLS Downgrade & Import/SSRF Guards**: Expanded `sameEndpointAndSecurity` (`tlsSecurityLevel`) across `PostgreSQL`, `KingbaseES`, `MySQL`, `MariaDB`, `TiDB`, `OceanBase`, `ClickHouse`, `SQL Server`, `Redis`, and `MongoDB` (including URI parameters) to block stored-secret reuse on any TLS downgrade; added `URI` SSRF validation, `2 MiB` / `500`-item transactional limits, and admin-shared visibility enforcement on connection profile imports; isolated `autocomplete` metadata caches per session for non-remembered shared connections; preserved existing `Vary: Origin` headers under gzip compression.
  - **Desktop Local Security & Child-Process Hygiene**: Required a valid boot ticket or local session cookie before serving `index.html` (`desktopToken`), enforced port-exact `Origin`, `Sec-Fetch-Site`, and JSON `Content-Type` CSRF checks on cookie-authenticated mutations, honored `MaxRows <= 0` unlimited exports in native save dialogs, switched macOS `osascript` dialogs to `argv` passing, reaped Linux browser/window child processes (`cmd.Wait()`), and tightened `0700`/`0600` local data directory permissions.
- **14-Driver Concurrency, Memory & SQL/NoSQL Sandbox Fixes**:
  - **SQL Base, ClickHouse, Oracle, Dameng, SQL Server & MySQL**: Stripped null bytes in identifier/literal formatters; pinned single-session `*sql.Conn` execution across `ApplyMutationsConn`, `StreamExportConn`, `StreamMultiTableExportConn`, and `BatchImportConn`; released `SQL Server` `BrowseData` connections before `COUNT(*)` to prevent pool deadlocks and bound `ApplyRowMutations`/`StreamExport`/`BatchImport` to `req.Database`; enforced restricted network dialers on `Oracle` & `Dameng` (blocking TNS `REDIRECT` SSRF) and strict `SID,SERIAL#` validation in `Oracle.KillSession`; enforced statement-by-statement `ValidateClickHouseRestrictedWebSQL` across query, batch import, streaming export, and `EXPLAIN` endpoints; disallowed `skip-verify` / `TrustServerCertificate=true` under restricted Web non-admin mode.
  - **DuckDB, SQLite & MongoDB**: Fixed comment-aware dot-command scanning (`--` and multi-line `/* ... */`), backed `:memory:` DuckDB sessions with isolated temp files (`Close()` auto-cleanup) and single-process multi-statement execution so session state and transactions persist reliably, added `jsonl` and `markdown` DuckDB streaming exports, unified `MongoDB` `resolveDBName`, preserved scalar `_id` values via `bson.D`, and supported `shard:opid` termination in sharded `MongoDB` `KillSession`.
- **Dark Mode Flash Prevention, Sticky Table Polish, Mobile/Safari Compatibility, Memory & i18n**:
  - **Zero-FOUC Dark Mode & Sticky Table Styling**: Added pre-render theme resolution (`main.tsx` + `prefers-color-scheme` CSS fallback + `<meta name="color-scheme" content="light dark" />`), opaque Dark Mode sticky column backgrounds (`#141414` workspace / `#1f1f1f` modal-drawer with hover states), filler-row anti-bleed styling, selected staged-new-row highlights, and `<Select>` search-input autofill refinements while preserving autofill suppression and Safari zoom prevention.
  - **Mobile (`360px`), Notch Safe-Area & Safari Input Fixes**: Fixed small-screen virtual-keyboard scroll traps on `LoginPage` (`100dvh` + `margin: auto`), adapted `WorkbenchLayout` bottom status bar and mobile `<Drawer>` footers to `env(safe-area-inset-bottom)`, converted mobile sidebar/modal widths to responsive CSS (`min(..., calc(100vw - 24px))`), and excluded Monaco `.ime-input` plus adjusted `24px` compact input `line-height` under iOS Safari `@supports (-webkit-touch-callout: none)`.
  - **Memory, Polling & 4-Locale i18n**: Paused `ServerMonitorTab` auto-polling while browser tabs are hidden (`visibilitychange`), skipped cold-start tab auto-hydration for locked `RememberPassword = false` connections, invalidated sidebar caches on connection edit/lock, guarded async tab races and clipboard fallbacks, made i18n `{var}` interpolation safe against literal `$` patterns, and completed 19 missing translations across `en-US`, `zh-CN`, `zh-TW`, and `ja-JP`.

## [v1.0.3] - 2026-11-08

### Session-Only DB Credentials by Default, CodeQL & Deep Security Hardening, Dark Mode & Mobile Ergonomics
- **Session-Only Database Credentials by Default & Interactive Auth Recovery (`ConnectionModal` + `ConnectionAuthModal`)**:
  - **Default Remember Password Off**: New network and URI database connections (`MySQL`, `MariaDB`, `TiDB`, `OceanBase`, `PostgreSQL`, `KingbaseES`, `ClickHouse`, `SQL Server`, `Oracle`, `Dameng DM8`, `Redis`, `MongoDB`) now default to **NOT saving database passwords or URI credentials to disk** (`RememberPassword = false`). Secrets are held purely in bounded per-session server memory (`POST /api/connections/{id}/unlock`) and automatically wiped on logout, session expiry, connection lock/delete, or process shutdown.
  - **Optional Encrypted Vault Persistence & Edit Turn-Off Wipe**: Users can opt in to **`Remember password`** per connection to persist AES-256-GCM encrypted credentials (`conns.enc`), and can uncheck **`Remember password`** at any time when editing an existing saved connection to immediately purge stored passwords and embedded URI secrets from disk.
  - **Interactive Unlock & Automatic Auth-Failure Re-Prompt**: Connecting to an unlocked session-only profile (`DB_AUTH_REQUIRED`) or hitting an upstream database credential rejection (`DB_AUTH_FAILED` across all 12 authenticated SQL/NoSQL drivers, including `ORA-01017` / `ORA-28000` / `ORA-28001`, PostgreSQL `28P01` / `28000`, MySQL `1045`, SQL Server `18456`, ClickHouse `516` / `401`, Redis `WRONGPASS` / `NOAUTH`, and MongoDB `AuthenticationFailed` `code 18`) opens an interactive **`ConnectionAuthModal`** allowing username/password correction, optional **`Remember password`** persistence, and seamless retry of the interrupted operation (including streaming exports and multi-tab auto-reload).
- **Security Policy (`SECURITY.md`), GitHub CodeQL Remediation & Backend Memory/Concurrency Hardening**:
  - Published DBHarbor's official **`SECURITY.md`** vulnerability disclosure policy and hardened all GitHub Actions workflows (`ci.yml`, `release.yml`, `preview.yml`) with least-privilege `contents: read` top-level `GITHUB_TOKEN` permissions and job-scoped write grants.
  - Remediated static analysis & security findings across Go and TypeScript: guarded saved-secret reuse (`sameEndpointAndSecurity`) against URI swaps and TLS downgrades (`UseSSL` deactivation or `SSLSkipVerify` activation), blocked cross-owner secret duplication in Web Server Edition, allowed authorized non-admin Web users to unlock shared `RememberPassword = false` connections within their own session scope, unified ClickHouse & Redis TLS config builders (SNI `ServerName` + non-admin `skipVerify` restriction), enforced raster-only `data:image/(png|jpeg|gif|webp|bmp|x-icon);base64` validation on custom branding favicons, URL-encoded path segments across API clients, and bounded `int32`/`uint32` integer conversions.
  - Hardened server memory & file-lock safety: bounded in-memory `sessionCreds` (`4096` scopes / `256` entries per scope) with shutdown zeroing, switched driver pool eviction to composite `(connID + sessionKey)` keys (`maxPools = 128`) so non-remembered sessions never evict shared pools, delayed `Content-Disposition: attachment` headers on streaming SQL/Document exports until query open succeeds, and prevented DuckDB CLI `> 32 MiB` stdout pipe deadlocks and file-lock retention on delete/update.
- **Dark Mode Visual Polish, Startup Tab Hydration & Mobile (`360px`) Compatibility**:
  - Eliminated light-gray scrollbar tracks on dark tables/modals (`transparent` scrollbar track), prevented white background flashes before Monaco SQL/JSON editors mount in Dark Mode, and synchronized dynamic `<meta name="theme-color">` with Light (`#ffffff`) and Dark (`#141414`) themes.
  - Gated persisted tab auto-reconnection on `/api/system/bootstrap` completion (`bootstrapped`) so refreshing with open session-only tabs never fires premature requests or flashes raw error banners, and wired automatic post-unlock data reload across all 8 database workspace tabs (`Overview`, `TableData`, `TableStructure`, `SqlConsole`, `RedisBrowser`, `MongoCollection`, `DbUsers`, `ServerMonitor`).
  - Improved `360x800` mobile ergonomics: wrapped `ServerMonitorTab` header toolbars to eliminate horizontal overflow, replaced cramped `Segmented` switchers on mobile in `ConnectionSidebar` (`Shared / Personal`) and `SchemaObjectModal` with compact full-width selectors, tightened mobile `<Drawer>` paddings (`12px`), stacked local single-file path inputs cleanly, and suppressed unwanted mobile virtual-keyboard auto-popups on modal open.

## [v1.0.1] - 2026-11-07

Persistent server configuration (`<DataDir>/config.json`), Initial Administrator Setup Wizard, Login Branding, Emergency Admin Recovery Mode (`recovery` / `-recover-admin`), and Web Server local-file/network sandboxing apply **exclusively to Web Server Edition (`dbharbor-*`)**.

### Persistent Server Config, Emergency Admin Recovery, Security Hardening, Mobile Touch UX & Service Upgrade
- **Persistent Server Configuration (`<DataDir>/config.json`) & Emergency Admin Recovery Mode *(Web Server Edition Only)***:
  - Web Server Edition now auto-generates `<DataDir>/config.json` (`0600` permissions; override path via `-config <path>` or `DBHARBOR_CONFIG_FILE`) with 4-tier precedence (`CLI flags > DBHARBOR_* env vars > config.json > defaults`), covering `host`, `port`, `unixSocket`, `unixSocketPerm`, `unixSocketGroup`, `idleConnTTLMinutes`, `maxImportMB`, `trustedProxies`, `corsAllowedOrigins`, `security` (`allowPrivateNetworkForNonAdmin`, `duckdbCliPath`), and `recovery` (`enabled`, `adminUsername`, `newPassword`, `reset2FA`).
  - Added dual emergency recovery workflows when the Web Server administrator password or 2FA authenticator/recovery codes are lost:
    1. **Config File Recovery**: Edit `<DataDir>/config.json` to set `"recovery": { "enabled": true, "adminUsername": "admin", "newPassword": "YourNewStrongPassword", "reset2FA": true }` (min 8 chars, or `"newPassword": "auto"` to generate a random 16-char password printed to startup logs) and restart DBHarbor — automatically snapshots `dbharbor.db` to `<DataDir>/.backups/`, resets the password/2FA, revokes existing sessions, and **immediately disarms `config.json` (`"enabled": false`, `"newPassword": ""`)** so plaintext credentials never remain on disk.
    2. **One-Shot CLI Recovery**: Run `dbharbor -data-dir <dir> -recover-admin [-recover-user <username>] -recover-pass <newPass|auto> [-reset-2fa]` to reset credentials and exit immediately.
- **Zero-Default-Credential Initial Setup Wizard, Login Branding & Anti-Search-Engine Indexing *(Web Server Edition Only)***:
  - Removed the legacy default `admin` / `admin123` fallback and standardized an **8-character minimum** initial admin password policy across Web Setup, CLI (`-admin-pass`), and service installers. When no bootstrap credentials are supplied and the user store is empty, the first visit opens a one-time **Initial Administrator Setup** wizard (`POST /api/auth/setup`) that permanently locks after the primary admin is created.
  - Redesigned the Sign-In page for zero unauthenticated information leakage: empty username field, zero default-password hints, no version/engine/GitHub disclosures before authentication, minimal `GET /api/health` (`{"status":"ok"}`), and authenticated-only `GET /api/version`.
  - Administrators can customize the browser tab `<title>`, top emblem (`Shield`, `Database`, `App Logo`, uploaded custom image `<= 128 KB` synced to Favicon, or hidden), main heading, and subtitle during initial setup or under **Security / 2FA -> Login Page**, backed by triple anti-crawler directives (`/robots.txt`, `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate` + `Referrer-Policy: no-referrer`, and `<meta name="robots">` / `<meta name="googlebot">`).
- **Security, Driver Reliability & Performance Hardening**:
  - **Web Server Local Database & SSRF Sandboxing**: Confined non-admin (`Read-Write`) local SQLite/DuckDB databases in Web Server Edition strictly within `<DataDir>/local_databases/` (blocking symlink traversal), disabled SQLite `ATTACH DATABASE` in Web Server mode, enforced server-controlled `security.duckdbCliPath` with DuckDB `enable_external_access = false`, and added a private/loopback/link-local SSRF network guard for non-admin connections (configurable via `security.allowPrivateNetworkForNonAdmin`).
  - **Auth Anti-Replay & Proxy-Aware Rate Limiting**: Upgraded Web Server login protection with vault-derived single-use CAPTCHA tokens, `trustedProxies`-aware client IP extraction (`X-Forwarded-For` / `X-Real-IP` trusted only from configured proxy IPs/CIDRs), and bounded 2FA challenge attempt limits.
  - **Verified TLS, Concurrency & Memory Fixes**: Added verified TLS modes across database drivers, fixed SQL Server `USE [db]` database context isolation on pooled connections, hardened `pool.Manager` with reference-counted concurrent leases so idle eviction never closes active queries, capped streaming DuckDB/MongoDB result memory footprints, added transactional startup SQLite metadata schema migrations (`schema_migrations` + `<DataDir>/.backups/` `VACUUM INTO` snapshots), and accelerated SQLite schema object listing into instant single-catalog queries.
- **Mobile Touch Workbench & Table Ergonomics**:
  - Switched mobile / coarse-pointer data grids to single-container native GPU CSS `position: sticky` headers (`.dbharbor-touch-sticky-grid`) with `ResizeObserver` hysteresis for zero-flicker scrolling, and added **touch column width drag-resizing** plus **double-tap auto-expand**.
  - Added touch-friendly `[⋮]` action buttons and long-press context menus across sidebar object trees and data grids, a mobile SQL Console quick-symbol bar, tap-to-inspect truncated cell previews, `34px–40px` touch targets with destructive action (`Truncate` / `Drop` / `Discard`) isolation, `keep-alive` sidebar mounting with in-memory object tree caching, and global viewport popup boundary clamping.
- **Cross-Platform Service Installer & Online Binary Upgrade (`install-service.sh` / `install-service.ps1`)**:
  - Added `upgrade` (and `update` alias) / `-Action Upgrade` (and `-Action Update` alias) for one-command online downloads from GitHub Releases with **fail-closed `SHA256SUMS.txt` verification**, pre-install `-version` binary smoke checks, `--mirror` / `-Mirror` acceleration, and headless `--admin-user` / `--admin-pass` (`>= 8` chars) bootstrap.
  - Fixed quoted `systemd` `ExecStart=` and macOS `launchd` `ProgramArguments` custom install path preservation during upgrades, guarded Windows `irm | iex` `$ScriptDir` resolution and `%TEMP%` cleanup, and eliminated Windows `.exe` file-lock races via graceful shutdown polling (`Stop-DBHarborServiceAndWait`) + atomic `.old` binary hot-replacement.

### Initial Release
- **Dual Editions — Native Desktop GUI & Web Server (`CGO_ENABLED=0`)**:
  - **Desktop GUI Edition (`dbharbor-desktop-*` & macOS `DBHarbor.app`)**: Double-click native GUI window (`Win32 + Edge WebView2` on Windows with `-H=windowsgui` zero console window, `Cocoa NSWindow + WKWebView` on macOS, `GTK3 + WebKit2GTK` on Linux) operating in **pure local mode** without any account/login system, native dark OS title bar sync, native file dialogs for `.db/.sqlite/.duckdb` selection & Save As exports, multi-window local session isolation, and AES-256-GCM encrypted local connection vault.

- **14 Built-in Database Engines**: Pure-Go (`CGO_ENABLED=0`) drivers for ClickHouse (Native TCP & HTTP + partition governance), DuckDB, MySQL, MariaDB, TiDB, OceanBase, PostgreSQL, KingbaseES, SQLite 3, SQL Server, Oracle (no Instant Client required), Dameng DM8, Redis (DB0–15 browser, 6 data structures, JSON key backup/restore, CLI), and MongoDB (JSON/Table views, BSON CRUD, JSON/JSONL document import & export, indexes, `RunCommand`).
