## [v1.0.1] - 2026-11-07

> **Edition Scope Note**: **Desktop GUI Edition (`dbharbor-desktop-*` / `DBHarbor.app`)** continues to operate in **pure zero-login local mode with NO user account system**. Persistent server configuration (`<DataDir>/config.json`), Initial Administrator Setup Wizard, Login Branding, Emergency Admin Recovery Mode (`recovery` / `-recover-admin`), and Web Server local-file/network sandboxing apply **exclusively to Web Server Edition (`dbharbor-*`)**.

### Persistent Server Config, Emergency Admin Recovery, Security Hardening, Mobile Touch UX & Service Upgrade
- **Persistent Server Configuration (`<DataDir>/config.json`) & Emergency Admin Recovery Mode *(Web Server Edition Only)***:
  - Web Server Edition now auto-generates `<DataDir>/config.json` (`0600` permissions; override path via `-config <path>` or `DBHARBOR_CONFIG_FILE`) with 4-tier precedence (`CLI flags > DBHARBOR_* env vars > config.json > defaults`), covering `host`, `port`, `unixSocket`, `unixSocketPerm`, `unixSocketGroup`, `idleConnTTLMinutes`, `maxImportMB`, `trustedProxies`, `corsAllowedOrigins`, `security` (`allowPrivateNetworkForNonAdmin`, `duckdbCliPath`), and `recovery` (`enabled`, `adminUsername`, `newPassword`, `reset2FA`).
  - Added dual emergency recovery workflows when the Web Server administrator password or 2FA authenticator/recovery codes are lost:
    1. **Config File Recovery**: Edit `<DataDir>/config.json` to set `"recovery": { "enabled": true, "adminUsername": "admin", "newPassword": "YourNewStrongPassword", "reset2FA": true }` (min 8 chars, or `"newPassword": "auto"` to generate a random 16-char password printed to startup logs) and restart DBHarbor — automatically snapshots `dbharbor.db` to `<DataDir>/.backups/`, resets the password/2FA, revokes existing sessions, and **immediately disarms `config.json` (`"enabled": false`, `"newPassword": ""`)** so plaintext credentials never remain on disk.
    2. **One-Shot CLI Recovery**: Run `dbharbor -data-dir <dir> -recover-admin [-recover-user <username>] -recover-pass <newPass|auto> [-reset-2fa]` to reset credentials and exit immediately.
- **Zero-Default-Credential Initial Setup Wizard, Login Branding & Anti-Search-Engine Indexing *(Web Server Edition Only)***:
  - Removed the legacy default `admin` / `admin123` fallback and standardized an **8-character minimum** initial admin password policy across Web Setup, CLI (`-admin-pass`), and service installers. When no bootstrap credentials are supplied and the user store is empty, the first visit opens a one-time **Initial Administrator Setup** wizard (`POST /api/auth/setup`) that permanently locks after the primary admin is created.
  - Redesigned the Sign-In page for zero unauthenticated information leakage: empty username field, zero default-password hints, no version/engine/GitHub disclosures before authentication, minimal `GET /api/health` (`{"status":"ok"}`), and authenticated-only `GET /api/version`.
  - Administrators can customize the browser tab `<title>`, top emblem (`Shield`, `Database`, `App Logo`, uploaded custom image `<= 128 KB` synced to Favicon, or hidden), main heading, and subtitle during initial setup or under **Security / 2FA -> Login Page**, backed by triple anti-crawler directives (`/robots.txt`, `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex, notranslate` + `Referrer-Policy: no-referrer`, and `<meta name="robots">` / `<meta name="googlebot">`).
- **Security, Driver Reliability & Performance Hardening**:
  - **Web Server Local Database & SSRF Sandboxing**: Confined non-admin (`Read-Write`) local SQLite/DuckDB databases in Web Server Edition strictly within `<DataDir>/local_databases/` (blocking symlink traversal), disabled SQLite `ATTACH DATABASE` in Web Server mode, enforced server-controlled `security.duckdbCliPath` with DuckDB `enable_external_access = false`, and added a private/loopback/link-local SSRF network guard for non-admin connections (configurable via `security.allowPrivateNetworkForNonAdmin`).
  - **Auth Anti-Replay & Proxy-Aware Rate Limiting**: Upgraded Web Server login protection with vault-derived single-use CAPTCHA tokens, `trustedProxies`-aware client IP extraction (`X-Forwarded-For` / `X-Real-IP` trusted only from configured proxy IPs/CIDRs), and bounded 2FA challenge attempt limits.
  - **Verified TLS, Concurrency & Memory Fixes**: Added verified TLS modes across database drivers, fixed SQL Server `USE [db]` database context isolation on pooled connections, hardened `pool.Manager` with reference-counted concurrent leases so idle eviction never closes active queries, capped streaming DuckDB/MongoDB result memory footprints, added transactional startup SQLite metadata schema migrations (`schema_migrations` + `<DataDir>/.backups/` `VACUUM INTO` snapshots), and accelerated SQLite schema object listing into instant single-catalog queries.
- **Mobile Touch Workbench & Table Ergonomics**:
  - Switched mobile / coarse-pointer data grids to single-container native GPU CSS `position: sticky` headers (`.dbharbor-touch-sticky-grid`) with `ResizeObserver` hysteresis for zero-flicker scrolling, and added **touch column width drag-resizing** plus **double-tap auto-expand**.
  - Added touch-friendly `[⋮]` action buttons and long-press context menus across sidebar object trees and data grids, a mobile SQL Console quick-symbol bar, tap-to-inspect truncated cell previews, `34px–40px` touch targets with destructive action (`Truncate` / `Drop` / `Discard`) isolation, `keep-alive` sidebar mounting with in-memory object tree caching, and global viewport popup boundary clamping.
- **Cross-Platform Service Installer & Online Binary Upgrade (`install-service.sh` / `install-service.ps1`)**:
  - Added `upgrade` (and `update` alias) / `-Action Upgrade` (and `-Action Update` alias) for one-command online downloads from GitHub Releases with **fail-closed `SHA256SUMS.txt` verification**, pre-install `-version` binary smoke checks, `--mirror` / `-Mirror` acceleration, and headless `--admin-user` / `--admin-pass` (`>= 8` chars) bootstrap.
  - Fixed quoted `systemd` `ExecStart=` and macOS `launchd` `ProgramArguments` custom install path preservation during upgrades, guarded Windows `irm | iex` `$ScriptDir` resolution and `%TEMP%` cleanup, and eliminated Windows `.exe` file-lock races via graceful shutdown polling (`Stop-DBHarborServiceAndWait`) + atomic `.old` binary hot-replacement.

## [v1.0.0] - 2026-11-07

### Initial Release
- **Dual Editions — Native Desktop GUI & Web Server (`CGO_ENABLED=0`)**:
  - **Desktop GUI Edition (`dbharbor-desktop-*` & macOS `DBHarbor.app`)**: Double-click native GUI window (`Win32 + Edge WebView2` on Windows with `-H=windowsgui` zero console window, `Cocoa NSWindow + WKWebView` on macOS, `GTK3 + WebKit2GTK` on Linux) operating in **pure local mode** without any account/login system, native dark OS title bar sync, native file dialogs for `.db/.sqlite/.duckdb` selection & Save As exports, multi-window local session isolation, and AES-256-GCM encrypted local connection vault.
  - **Web Server Edition (`dbharbor-*`)**: Standalone single-file web workbench supporting both TCP and native `AF_UNIX` Unix Domain Socket listening (`-unix-socket`, `-unix-socket-perm`, `-unix-socket-group`), automatic stale socket cleanup, `X-Forwarded-For` / `X-Real-IP` resolution, server-side local database directory browser & `.db/.sqlite/.duckdb` upload, and production reverse proxy templates for Nginx, Caddy, and Apache (`deploy/`).
- **14 Built-in Database Engines**: Pure-Go (`CGO_ENABLED=0`) drivers for ClickHouse (Native TCP & HTTP + partition governance), DuckDB, MySQL, MariaDB, TiDB, OceanBase, PostgreSQL, KingbaseES, SQLite 3, SQL Server, Oracle (no Instant Client required), Dameng DM8, Redis (DB0–15 browser, 6 data structures, JSON key backup/restore, CLI), and MongoDB (JSON/Table views, BSON CRUD, JSON/JSONL document import & export, indexes, `RunCommand`).
- **Full Visual Schema Designer, Navicat-Style Data Grid, Routines/Triggers & Streaming Transfer**:
  - Visual column add/modify/rename/drop, index create/modify/drop & foreign key management, SQL template generator, table rename/clone, `CREATE VIEW`, visual & dialect-smart `CREATE / EDIT PROCEDURE, FUNCTION & TRIGGER`, database-level user & privilege governance (`GRANT` / `REVOKE` / Redis ACL / MongoDB roles), transactional lossless SQLite table rebuilds, and live DDL preview.
  - Full-height spreadsheet-grade data grid with bottom-pinned horizontal scrollbar, click-blank-row direct insertion, multi-row batch column editing, single/multi-row TSV clipboard copy & paste (`Ctrl+C` / `Ctrl+V` compatible with Notepad & Excel), and multi-tab selective-feature Monaco SQL Console (`Ctrl/Cmd + Enter`, `EXPLAIN`, SQL formatter, `AbortController` cancellation, instant client-side result file save, history, and snippets).
  - Mobile-first (`<= 640px`) responsive workbench layout featuring a compact header, single-pill tab switcher, collapsible filter bar, sticky mutation/selection footer, `85dvh` bottom-sheet row editor, and `Keys | Value | CLI` Redis mobile switcher.
  - Streaming full-database SQL Dump, multi-table/filtered/query/MongoDB export (`SQL`, `CSV-BOM`, `CSV`, `JSON`, `JSONL`, `Markdown`), batched transactional file imports, and direct paste-to-execute SQL scripts.
- **Enterprise Web Multi-User RBAC, Security & Service Governance**:
  - Web Server Edition includes multi-user 3-tier RBAC (`Admin` / `Read-Write` / `Read-Only`) with shared/private connection isolation, sliding-window IP/account anti-bruteforce rate limiting (`HTTP 429`), stateless HMAC SVG captcha, offline SVG QR code RFC 6238 TOTP 2FA + 8 single-use recovery codes, revocable device sessions, and security audit logs.
  - Runtime metadata and `.secret.key` default to OS-standard application data directories (`%LOCALAPPDATA%\DBHarbor\data` / `%ProgramData%\DBHarbor\data` on Windows, `~/Library/Application Support/DBHarbor/data` on macOS, `$XDG_DATA_HOME/dbharbor` or `/var/lib/dbharbor` on Linux) rather than the working directory, with auto-start service installers (`install-service.sh`, `install-service.ps1`) supporting explicit user roles and permission groups.
- **English-First Codebase, Multi-Language UI & Online Update Reminder**:
  - Built-in real-time i18n UI & documentation in **English (`en-US`)**, **Simplified Chinese (`zh-CN`)**, **Traditional Chinese (`zh-TW`)**, and **Japanese (`ja-JP`)**.
  - Online version & changelog checker synced with `Willh92/DBHarbor` on GitHub with proactive update notification, auto-reminder toggle switch, per-version skip, automatic desktop vs server asset matching, and licensed under **Apache License 2.0 (`Apache-2.0`)**.
